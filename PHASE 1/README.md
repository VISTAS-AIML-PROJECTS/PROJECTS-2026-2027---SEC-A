**Project Title**
**AI-Powered Smart Aquaculture Assistant: Smart Fish Stress Prediction & Water Quality Management System**

**Team**
Team Number:10

**Project Description**
Smart Aquaculture Assistant is an AI and IoT-based system designed to monitor important water conditions in aquaculture environments and provide fish health status.

The system uses an ESP32 with sensors to collect water-related parameters. The collected information can be monitored through a Streamlit dashboard.

**Main Technologies**
- Python
- Machine Learning
- Random Forest
- ESP32
- Streamlit
- Arduino IDE
- Jupyter Notebook

**Phase 1**
Phase 1 focuses on developing the software, machine learning model, IoT sensor monitoring, documentation, and project presentation.
